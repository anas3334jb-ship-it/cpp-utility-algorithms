# C++ Utility Programs: Array Min/Max & Binary to Decimal Converter

A beginner-friendly collection of essential C++ algorithms demonstrating array operations and numerical base conversions.

---

## 📌 Included Programs

1. **Array Min & Max Finder (`array_min_max.cpp`)**
   - Finds the smallest (minimum) and largest (maximum) numbers from an array of integers.

2. **Binary to Decimal Converter (`binary_to_decimal.cpp`)**
   - Converts a user-provided binary number (base-2) into its decimal equivalent (base-10).

---

## 🛠️ Requirements & Prerequisites

- **Language:** C++
- **Compiler:** `g++` (GCC) or any standard C++ compiler
- **IDE/Editor:** VS Code, CLion, Dev-C++, or Terminal
